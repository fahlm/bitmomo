# Bitmomo Documentation

This directory is the central documentation layer for the Bitmomo project.

## Planned areas

- `strategy/` — business, product, audience, and monetization strategy.
- `brand/` — positioning, visual identity, voice, and brand guidelines.
- `content/` — content formats, editorial standards, YouTube, and X workflows.
- `research/` — research methodology, market-analysis frameworks, and source standards.
- `website/` — website architecture, technical decisions, deployment, SEO, and performance notes.

## Working principle

Documentation should capture decisions, repeatable processes, and specifications so that future AI agents and collaborators can execute work consistently without relying on undocumented context.
